# hospital-noshow-analysis-mysql-powerbi
An end-to-end Healthcare Data Analytics project using MySQL and Power BI to analyze patient appointment no-show patterns and deliver data-driven recommendations to reduce hospital resource waste.

Tools & Technologies Used
- **MySQL Workbench:** Data cleaning, manipulation, and SQL querying.
- **Power BI:** Interactive dashboard design and visualization.
- **Microsoft Word / PDF:** Comprehensive business and technical reporting.

Key Insights & Findings
- **SMS Reminders:** Patients who received SMS notifications showed a significantly lower no-show rate compared to those who did not.
- **Day-of-Week Trends:** No-show rates varied notably across different weekdays, peaking on specific days.
- **Age Demographics:** Working-age adults exhibited higher rates of missed appointments due to busy schedules.

Repository Structure
- Medical Appointment No-Show Analysis.sql : Complete SQL script containing data queries and analysis.
- power bi dashboard.pbix : Interactive Power BI dashboard file.
- Patient Appointment No-Show Analysis.pdf : Full project report and documentation.
